首发平台：macOS 与 Windows。一次性个人授权 **9.9 元**，本人最多两台设备，Mac / Windows 可组合使用，包含购买后至少一年更新；权益覆盖的版本可持续使用。

当前为发布验收材料，正式签名、目标系统与购买交付尚在检查，本地页面不提供付款入口。请先试用再决定购买，实际可售状态以正式订单页为准。

## 下载与检查

下载订单指定的 GitHub Release（发行版）附件中的 ZIP；同一系统的买家共用安装包，每笔订单的授权码不同。无需下载源代码或卖家的签发工具。不要把 仓库的“下载源码 / ZIP” 当作可运行安装包。

校验清单是同一发行版附件中的 `SHA256SUMS`（本地展示目录内为 `packages/SHA256SUMS`）。Mac 可用 `shasum -a 256 <ZIP文件>`，Windows PowerShell 可用 `Get-FileHash <ZIP文件> -Algorithm SHA256` 核对。不要因安装提示而全局关闭系统安全防护。

已购买用户请保留订单对应版本的发行页；后续最新版可能超出旧订单更新权益，旧版不强制升级。GitHub 只承担下载，付款、授权找回和售后仍在原购买平台完成；当前尚无已发布下载地址。

### Mac

完整解压 ZIP，将 `JSONPick.app` 放入“应用程序”或自己的目录后打开。本地验收包当前是临时签名、未公证，不能将当前材料当作已通过 Apple 公证或所有设备安装通过。

未公证应用可能被系统阻止首次打开。只有确认来自可信来源、校验值一致且无篡改时，才按 [Apple 官方说明](https://support.apple.com/en-us/102445)在“系统设置 → 隐私与安全性”中针对这一应用确认“仍要打开”。这不是关闭整个系统的安全防护；受组织管理的设备可能不允许此操作，应遵守组织策略。本项目正在验证安装流程，不能保证所有受管设备允许安装。

### Windows

完整解压 ZIP，进入 `windows-amd64` 目录，双击 `JSONPick.exe`。不要在 ZIP 预览窗口里直接运行。

缺少 WebView2 时，使用 [Microsoft 官方安装入口](https://developer.microsoft.com/microsoft-edge/webview2/)；JSONPick 不自动安装运行时。遇到系统拦截或启动错误，先保留版本与提示，通过购买平台反馈，不需要发送生产日志。

## 试用与激活

1. 商业版首次运行开始连续 14 天试用；在右上角“试用 / 激活授权”查看状态。
2. 下单后通过购买平台取得这一单的完整 `JP1.` 授权码，卖家首期人工交付。
3. 在“试用与授权”粘贴整行，选择“导入并激活”，核对授权编号与更新截止日期。
4. 同一个码可在本人最多两台设备导入，包括一台 Mac 加一台 Windows；离线首版按许可约定执行设备数量，没有联网硬件绑定。
5. 已授权版本可持续使用；一年是包含的更新权益，不是旧版本到期停用。

试用结束暂停新的解析 / 展开 / 对比，原文与已有结果仍可复制或主动保存。程序不自动保存工作区，退出前请主动导出。
