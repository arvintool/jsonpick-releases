# JSONPick 隐私说明

适用版本：0.1.33 本地预览版及同版本商业候选版。此版本尚未公开启售；正式经营主体和售后入口仍待发布者补充。

- 日志提取、解释、解码、查看、Filter、列导出、定义生成和结构对比在用户设备上处理，不将原始日志提交给服务器。
- 默认不保存输入、工作区或剪贴板历史，不植入使用遥测。清空、打开文件或替换示例前可保留一份最多 32 MiB 的内存恢复点；关闭应用后不恢复。
- 当前结果另保留其对应输入的一份内存引用（输入上限 32 MiB），用于按来源范围显示未经改写的原始日志；重新提取成功时替换，清空或关闭时释放。编辑或取消处理时保留上次结果与对应来源，不累计历史记录。
- “保存原文”“保存结果”“另存为”只在本人操作并选择位置后导出文件。桌面版先写同目录临时文件，成功后替换目标；取消保存不改写原文件。浏览器版由浏览器管理下载位置。
- 主题、外部媒体策略、离线模式和表格导出策略可保存到 WebView 本地存储；其中不保存日志、URL、筛选值或授权码。
- 外部图片 / 视频默认需要点击加载。也可关闭外部媒体，或自行允许悬停加载。加载和另存为会访问媒体地址，目标服务可能接收 IP 和 URL 参数；不会修改签名参数。内置示例无需访问外部媒体地址。
- 离线模式关闭应用发起的外部媒体请求，并停止进行中的外部媒体保存；不改变系统网络设置。浏览器首次加载网页和本机解析引擎仍需要站点静态资源，不能将网页设置等同于浏览器断网运行。
- 图片保存上限 20 MiB / 30 秒，视频 100 MiB / 2 分钟。保存器不使用其他浏览器的登录态；媒体源站权限和浏览器跨域限制可能影响保存。
- 剪贴板只在本人执行粘贴、复制或相应快捷键时读写，不后台监听。复制诊断信息只含程序版本、构建类型、系统 / 架构与构建信息，不附日志、剪贴板、地址、用户名、机器名或授权码。
- 商业候选在系统用户配置目录的 JSONPick/license.json 保存本机试用时间和导入授权；预览版不启用付费门禁。授权信息不包含日志。无账户、云同步、硬件指纹采集、在线设备核验或自动更新服务。
- 可删除本机偏好和授权状态；删除授权前应保留购买记录与原码。应用不保证清除操作系统交换文件、备份、浏览器缓存或用户主动导出的副本。

反馈问题请优先提供版本、步骤和合成最小示例，无需提供生产日志、令牌或真实个人信息。将来的联网、持久化和交易能力须另行说明并由用户选择。
