# JSONPick 使用与许可说明

适用版本：0.1.33。状态：本地预览与商业候选验收，尚未公开启售；发行主体、购买和售后入口仍待本人补充。本说明不能替代正式平台条款和适用法律。

## 构建类型

- 预览版：本地开发 / 预览使用，没有付费限制；不追溯要求旧预览版购买授权。
- 商业候选：同版本功能，首次运行提供连续 14 天试用，使用离线签名授权。仍用于本地验收，没有自动收款 / 发码或对外销售服务。
- 在“帮助与设置”中查看实际构建类型、版本和发行日期，不能仅根据安装包文件名判断是否为商业版。

## 商业候选许可约定

个人许可供购买者本人最多两台自用设备使用，包括本人工作使用；不包含转售、共享授权码或分发自有源码的权利。离线首版按许可约定执行设备数，不自动联网绑定设备。

授权所含更新截止日以内发布的版本可持续使用，不因更新权益期结束停止原版本日常使用。后续新版超出权益范围时，可以保留已获许可的旧版。正式售卖前需确认实际交付和承诺更新期匹配。

试用结束后暂停新的解析、结构展开与对比；原文、已有结果的复制和主动保存仍可使用。应用默认不保存工作区，关闭前请自行导出。

授权码由购买渠道订单找回；离线许可不能即时远程撤销，不能声称退款后已自动封禁。交付、质量、退款与争议按实际渠道规则及适用法律处理，不排除依法享有的权利。

## 功能与数据边界

解释结果可能无法还原原对象类型；错误和截断内容只展示可确认部分，不补造缺失值。代码定义是新定义草稿，需按项目依赖、协议编号和业务类型审阅。

输入 32 MiB、片段 8 MiB、200 个结果、50,000 节点 / 128 层及工作量预算仍适用；资源限制不代表语法错误。文本导出上限 64 MiB。

表格文本保护可能增加制表前缀，适用于表格软件查看，不适合作为程序原样导入；不同表格软件行为需验证。SQL IN 是待复核的片段，不连接或自动执行数据库操作，优先使用参数化输出。
